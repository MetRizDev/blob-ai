# 🟠 Blob

Милый ИИ-помощник в виде жёлто-оранжевой капли с большими глазами и ртом. Живёт в правом нижнем углу экрана, реагирует на курсор, отскакивает от краёв, строит эмоции, говорит голосом или «звуками как в Undertale», умеет безопасно помогать с экраном и рисовать картинки.

## Что внутри

- **Живой блоб** — перетаскивается мышью, мягко деформируется как шар с водой, отскакивает от границ экрана, при желании закрепляется на месте. Правый клик открывает меню.
- **40 эмоций** — каждая со своим предметом-символом (солнышко, зонтик, лупа, кубок, лампочка…). Модель сама выбирает эмоцию через токен `[emotion:id]` в системном промпте.
- **Короткие ответы** и полностью редактируемый системный промпт.
- **Голос** — три режима: без звука, системный `speechSynthesis` (выбор голоса, скорость, высота) и процедурные звуки в стиле Undertale (4 набора: classic / sans / papyrus / flowey).
- **Инструменты с подтверждением** — скриншот, перемещение курсора, клики, клавиши, ввод текста, прокрутка, открытие программ из белого списка. **Перед каждым действием** показывается карточка «Разрешить / Запретить».
- **Безопасность** — запрещены удаление, форматирование, системные команды, PowerShell/cmd, скрипты и программы вне белого списка. Ключ API шифруется через Windows DPAPI (`safeStorage`).
- **Генерация изображений** — если провайдер поддерживает `/images/generations`, картинка появляется в чате с кнопкой скачивания.
- **Интерфейс в стиле iOS 26** — стеклянные панели, мягкие пружинные анимации, светлая/тёмная тема, акцентные цвета, масштаб, 7 вкладок настроек и много персонализации.

## Сборка EXE через GitHub Actions

1. Распакуйте `blob.zip`.
2. Создайте новый GitHub-репозиторий и загрузите туда содержимое папки `blob` (вместе с `.github/workflows/build.yml`).
3. Нажмите **Actions → Build Blob EXE → Run workflow** (или отправьте тег `v1.0.0` — тогда ещё создастся Release).
4. После завершения скачайте артефакт **Blob-Windows** — внутри `Blob-1.0.0-x64.exe` (установщик) и `Blob-Portable.exe`.
5. Запустите EXE, откройте чат (клик по блобу или `Ctrl+Shift+B`), зайдите в **Настройки → ИИ** и вставьте API-ключ.

Workflow: `.github/workflows/build.yml`, сборка: `npm install && npm run dist` (Windows + Node 20 + electron-builder).

## Локальная разработка

Нужен Node.js 20+:

```powershell
npm install
npm run dev      # Vite + Electron
npm run build    # только компиляция
npm run dist     # сборка EXE в dist-release/
```

## Поддерживаемые провайдеры

OpenAI, OpenRouter, Groq, DeepSeek и любой OpenAI-совместимый endpoint (например, локальный LM Studio). Провайдер, базовый URL, модель, модель для картинок и ключ меняются в настройках.

## Важно про безопасность

Блоб **никогда** не выполняет действие без вашего явного подтверждения в чате. Если модель попросит нажать кнопку, ввести текст или открыть программу — появится отдельная карточка. Запрещённые действия блокируются ещё до показа карточки. Не отключайте инструменты и не добавляйте в белый список системные утилиты, если не уверены в необходимости.

Настройки хранятся в `%APPDATA%\blob\settings.json`.
